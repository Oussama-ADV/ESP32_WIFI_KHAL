# ESP32_WIFI_KHAL
Funny ESP32 WiFi project - Algeria

# 😂 ESP32 WiFi - Le projet du KHAL 🇩🇿

Un projet électronique humoristique réalisé avec ESP32.

## 🎬 Présentation

كي تكون خال ويقولولك بارطاجيلنا الويفي 😂

Ce projet a été créé pour divertir et montrer les possibilités de l'ESP32.

## 🔧 Matériel utilisé

- ESP32 DevKit
- Câble USB
- Ordinateur
- Smartphone pour tester

## 💻 Installation

1. Installer Arduino IDE.
2. Installer le support ESP32.
3. Télécharger le fichier ESP32_WIFI_KHAL.ino.
4. Ouvrir le sketch dans Arduino IDE. (ESP32_WIFI_KHAL.ino)
5. Ajouter la VIDEO préféré dans un dossier nommé : data, sans oublier de la nommée 1.mp4
6. Sélectionner la bonne carte ESP32.
7. Sur arduino IDE clique :CTRL+SHIFT+P puis ecris : LittleFS (ou a chaque fois tu change du video)
8. Téléverser le programme.
